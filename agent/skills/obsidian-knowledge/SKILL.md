# Obsidian の知識運用

- 話題に関係する過去情報が必要なときだけ Obsidian MCP で `share/` を検索し、必要なノートだけ読む。個人文脈が不要なら `share/memory/` は開かない。現在の事実は必要に応じて原典や現行コードで確認する。
- 保存はユーザーが明示的に依頼したときだけ行う。保存先は、調査時点の結果なら `share/reports/`、現在有効な再利用知識や手順なら `share/knowledges/`、ユーザーの個人情報・好み・継続的な事情なら `share/memory/` とする。
- 保存前に `share/AGENTS.md` と対象フォルダの `GUIDELINES.md` があれば読む。既存ノートを探し、命名・更新・退避のルールに従う。レポートの MCP 保存では、完成した新版を確認してから旧版を退避する。
- Obsidian MCP が使えない場合は参照・保存できなかったことを伝える。Codex・Claude・Serena の Memory や vault の直接ファイル操作へ切り替えない。
