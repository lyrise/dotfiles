# Obsidian の外部記憶運用

## 構成

```
share/
├── records/                  # 不変。書いたら変えない時点の記録
│   ├── YYYY-MM-DD-<topic>.md
│   └── archived/             # 同じトピックの新しい記録に置き換えられた旧記録
│       └── YYYY/
│           └── MM/
│               └── YYYY-MM-DD-<topic>.md
└── notes/                    # 現在有効な状態に保つノート
    ├── profile/              # ユーザー本人の情報・好み・継続的な事情
    │   └── <topic>.md
    └── knowledge/            # 汎用の技術・手順・環境の知識
        └── <topic>.md
```

- `records/` には調査結果、作業の経緯、判断とその理由など、その時点の事実を置く。種別は frontmatter の `tags` で表し、`date` を持たせる。
- `notes/` には現在も有効な内容だけを置き、frontmatter に `updated` を持たせる。1 トピック 1 ノートとし、同じトピックは既存ノートへ統合する。
- 特定リポジトリに固有の知識は vault に置かず、そのリポジトリ内の文書に置く。

## 参照

- 話題に関係する過去情報が必要なときだけ Obsidian MCP で `share/` を検索し、必要なノートだけ読む。個人文脈が不要なら `notes/profile/` は開かない。
- `records/` は記録時点の内容として扱い、現在の事実は必要に応じて原典や現行コードで確認する。
- `records/archived/YYYY/MM/` は、経緯や過去との比較が必要なときだけ開く。

## 保存・更新・整理

- 書き込みはユーザーが明示的に依頼したときだけ行う。時点の結果なら `records/`、現在有効な知識や手順なら `notes/knowledge/`、ユーザー本人の情報なら `notes/profile/` に置く。
- `notes/` へ保存する前に既存ノートを検索し、該当するノートがあれば新規作成せず更新する。
- `notes/` のノートは上書きで更新し、無効になったノートは削除する。旧版は残さず、残す価値のある経緯や判断理由だけを `records/` に書く。
- `records/` のノートは作成後に書き換えない。訂正や続報は新しい日付のノートとして書く。
- `records/` に保存する前に同じトピックの既存記録を検索する。ニュースの定期レポートのように同じトピックを新しい記録で置き換える場合は、新しい記録を保存して内容を確認してから、旧記録を内容とファイル名を変えずに `records/archived/YYYY/MM/` へ移す。`YYYY/MM` には旧記録のファイル名の日付を使う。退避先に同名ファイルがあれば上書きせず確認する。MCP に移動操作がなければ、複製を書いて内容を確認してから元のノートを削除する。

## 制約

- Obsidian MCP が使えない場合は参照・保存できなかったことを伝える。Codex・Claude・Serena の Memory や vault の直接ファイル操作へ切り替えない。
